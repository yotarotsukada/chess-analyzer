# 設計判断ログ（grilling の回答台帳）

grilling セッションで確定した回答の一覧。**回答者はこのファイルと矛盾する回答をしてはならない**。変更したい場合は「既存判断 Dn を覆す」と明示し理由を書く。

- 出典: `U` = ユーザー本人の回答 / `A` = 代理回答エージェントの回答。**A の判断は 2026-10-05 にユーザーが一括承認済み。**
- 用語は `../CONTEXT.md` に従う。調査結果は `research/` を参照。

## ユーザーの前提・好み（U）

- P1 会話・ドキュメントは日本語。
- P2 Next.js は絶対に使わない。React Router on Vite、サーバーも TypeScript、マイクロサービスに分けないモノリス。
- P3 最初は個人用、最終的に Web 公開し広告で収益化。既存アプリにない独自機能を持つ。
- P4 本人は主に Duolingo Chess で指している。

## 運用ルール（U）

- R1 MVP は main に直接実装し、サブエージェントでレビュー → 修正 → コミットする。
- R2 MVP 以降は、適切な粒度で Issue を切り、Issue に紐づいたスコープだけを main への PR で実装する。
