# ログインなしで、編集トークンによって所有を表す

> 注: X7 により、AI Commentary の生成依頼に限って会員登録を導入する予定（ADR 0007）。そのときにこの ADR を改める ADR を書く。匿名での Game の作成と、トークンによる所有は変えない。

アカウントやログインは作らない。Game の所有は、作成時に発行する編集トークンで表す。

- サーバーにはトークンのハッシュだけを保存する。
- Visitor のブラウザには、トークンと「自分の対局一覧」を保存する。
- 閲覧用の共有 URL とは別に、トークンを含む管理用リンクを発行する。管理用リンクを持つ人だけが、Game の削除と Player Color の修正をできる。

ログインをなくしたのは、広告で稼ぐサイトとして入口の手間を最小にするため。加えて、アカウント情報（メールアドレスやパスワード）を持たないことで、運用と法的な負担を減らすため。

## Consequences

- 管理用リンクでは、トークンを URL のフラグメントに入れる。フラグメントはサーバーのログ、Referer、アクセス解析、広告のスクリプトに送られないからだ。
- ブラウザに保存したトークンは、同じページで動く広告やアクセス解析のスクリプトからも読める。ただ、トークンでできるのは削除と Player Color の修正だけなので、被害は小さいとして受け入れる。
- ブラウザのデータを消し、管理用リンクも失った人は、自分の Game を管理できなくなる。救済は問い合わせ窓口で行う。
- 端末をまたいで「自分の対局一覧」を同期することはできない。
- 回数制限は、アカウントではなく、ブラウザ単位と IP 単位で行う。
- 将来アカウントを導入しても、Game の所有は編集トークンのままにする。トークンをアカウントに紐づけるかは、そのときに決める（AI Commentary の生成依頼にだけ会員登録を使う予定。ADR 0007）。
