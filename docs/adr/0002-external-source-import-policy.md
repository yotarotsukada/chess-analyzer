# 外部サービスからの Game の取り込み方針

規約上のリスクを避けるため、外部サービスからは次の方針でしか Game を取り込まない。

- **Chess.com**：2026年3月の規約改定で、許可のない自動アクセス・スクレイピング・AI によるアクセスの禁止が明記された。Chess.com には認証不要の公式 Published-Data API があり、他の商用サービスも使っている。それでも、広告付きサイトでの利用を明示的に許す文言がないため、書面で許可を得るまでは API も使わない。
- **Duolingo**：公式のエクスポート手段はない。規約は、スクレイピング・ロボット・リバースエンジニアリングを禁止している（規約の本文は JavaScript で描画されるため、検索結果の抜粋で確認した。2026-10 時点）。取り込みは、ユーザー本人の手入力と PGN の貼り付けに限る。ブラウザ拡張、DOM の読み取り、非公式の API は使わない。将来、画面から取り込む機能を作る場合も、ユーザー本人が撮った画像から盤面を認識し、保存するのは FEN や PGN に変換したデータだけにして、画像は保存しない。
- **Lichess**：規約で商用利用が認められている。公開 API を、Lichess のレート制限に従って使う（次の段階）。

Duolingo の Game を Review できることは、差別化の柱である。そのため「拡張機能で自動的に取り込めば便利」という提案は、何度も自然に出てくるはずだ。それを却下した理由として、この ADR を残す。

サービス名、ドメイン、画面に、Duolingo や Chess.com の商標やデザインを使わない。Chess.com の手の分類のグリフや配色も流用しない。説明のために名前に触れる場合は「非公式・提携なし」と明記する。
