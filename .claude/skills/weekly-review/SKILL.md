# 週次レビュー（D105）

## 手順

1. その週にマージした PR と、閉じた Issue を `gh` で集める。
2. `pnpm audit`、CI の失敗の履歴（不安定なテスト）、本番のエラー（エラー監視があれば）、`.claude/rules/` に反しているコードを確かめる。
3. 見つけたものを、Issue として最大3件起こす。`agent` などの着手のラベルは付けない（D103）。
4. 「週次まとめ YYYY-MM-DD」の Issue を1件作る。その週の変更（Issue ごとに1行）、起こした Issue、気になる点を書いて、すぐ閉じる。
5. ユーザーに3行で報告する。

完了条件：まとめの Issue があり、起こした Issue が3件以内で、どれも根拠（ファイル、コマンドの出力など）がある。
