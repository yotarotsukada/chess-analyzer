# DB のスキーマとマイグレーション（ADR 0011）

- スキーマを変えたら `pnpm db:generate` でマイグレーションを作る。生成された SQL を手で書き換えない。
- 変更は後方互換（expand / contract）に限る。デプロイを戻しても DB は戻らないので、直前の版のアプリが新しい DB で動ける必要がある。
  - 列やテーブルは足すだけにする。足す列は NULL を許すか、既定値を付ける。
  - 削除・名前の変更・型の変更は「足す → 移す → 消す」の別々の PR に分ける。
- マイグレーションを含む PR の「## 結果」には、「費用・データ・移行への影響」を必ず書く。
