# 画面（React Router）

- 文言は `app/i18n/ja.ts` に置き、`t()` で使う。用語は CONTEXT.md の表示名（「あなたの色」「疑問手」など）に合わせる。
- 利用者の多くはスマホの初心者。375px 幅で崩れないこと、タップで操作できることを確かめる。
- 意味を色だけで伝えない（文字のラベルを添える）。
- Game Review のページは検索エンジンに載せない（noindex。D30）。
- 外部のスクリプトやフォントを足さない（外部送信。D22、D57）。足す必要があればプライバシーポリシーとあわせてユーザーに確認する。
- 画面の振る舞いを変えたら `e2e/` に Playwright のテストを足す。
